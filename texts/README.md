# 게임 속 글 고치는 법

이 폴더에는 게임에 나오는 이야기와 안내 글이 들어 있습니다. 프로그램을 몰라도, GitHub 웹에서 바로 고칠 수 있어요.

| 파일 | 들어 있는 글 |
|---|---|
| `tutorial.md` | 첫 걸음: 장면 이름, 이야기 카드, 코치 말풍선, 틀렸을 때 힌트, 정리 카드 |
| `stories.md` | 스무하루의 밤: 밤마다 나오는 이야기 카드(시작 전 · 1 - 21번째 밤 · 3월 1일) |
| `crackdown.md` | 단속의 밤: 단속 카드의 이름 · 시기 · 배경 |
| `rules.md` | 「규칙 보기」 화면과 게임 중 [규칙] 팝업(규칙 한눈에) |
| `link.md` | 기기끼리 함께하기: 소개, QR로 연결하는 방법, 짧은 안내 |

## 고치는 순서

1. GitHub에서 고칠 파일을 엽니다(예: `texts/stories.md`).
2. 오른쪽 위 **연필 아이콘**(Edit this file)을 누릅니다.
3. 글을 고칩니다(아래 "글의 모양" 참고).
4. 아래쪽 **Commit changes**를 눌러 저장합니다.
5. 1 - 2분 뒤 게임 주소를 새로 고치면 바뀐 글이 보입니다. 휴대폰에 설치한 앱도 인터넷이 될 때 열면 새 글을 받아 옵니다.

## 글의 모양

```
## story.night.1.title
> 제목
2·8 독립선언
```

- `## 아이디` 줄 — 게임이 이 이름으로 글을 찾아요. **고치거나 지우지 마세요.**
- `>`로 시작하는 줄 — 어디에 보이는 글인지 적은 메모예요. 화면에는 나오지 않아요.
- 그 아래 — **여기가 화면에 나오는 글이에요. 여기만 고치면 됩니다.**
- 맨 위의 `# 제목` 줄과 설명은 보기 좋게 나눈 것이라 게임과 상관없어요.

## 글 안에서 쓸 수 있는 꾸밈

| 쓰는 법 | 화면 |
|---|---|
| `**굵게**` | **굵게** |
| 빈 줄 하나 | 문단 나눔 |
| 그냥 줄 바꿈 | 같은 문단 안에서 줄 바꿈 |
| 줄 앞에 `- ` | 점 목록 |
| 줄 앞에 `1. ` | 번호 목록 |
| `### 제목` · `#### 작은 제목` | 소제목 |
| 문단 앞에 `※ ` | 작고 흐린 글(덧붙이는 말) |
| `[주사위: 빨4 검4 흰4]` | 주사위 그림. 색은 흰 · 검 · 빨 · 파, 눈은 1 - 6. 같은 문단의 뒤 글은 그림 옆에 붙어요 |

HTML(`<b>` 같은 것)은 쓸 수 없어요. 쓰면 글자 그대로 보여요.

## 조심할 것

- **`{중괄호}`는 지우지 마세요.** 게임이 숫자나 이름을 끼워 넣는 자리예요. 예) `**{done} / {total}** 장면을 마쳤어요.` → 화면에는 "**3 / 14** 장면을 마쳤어요." 어떤 자리가 있는지는 메모(`>` 줄)에 적혀 있어요.
- **이름 · 제목은 짧게.** 메모에 "짧게"라고 적힌 글(장면 이름, 카드 이름 등)은 좁은 칸에 들어가요. 길면 두 줄이 될 수 있어요.
- **용어는 함께 바꾸세요.** 한뜻 · 연락망 · 한동네 · 밀정 · 흩어짐 · 감시 철수 같은 말은 여러 파일에 나와요. 하나를 바꾸면 다른 곳도 찾아 같이 바꿔 주세요(룰북 `docs/`도).
- **스무하루의 밤 카드를 더하려면** `story.night.번호.period` · `.title` · `.body` 세 개를 함께 적어요. 번호는 1 - 21(1번째 밤 = 2월 8일).
- **첫 걸음 단계 번호**(`hand.2.say`의 2 같은 것)는 장면 안 단계 순서예요. 글만 고칠 때는 신경 쓰지 않아도 돼요.

## 잘못 고쳤을 때

- 아이디를 지우거나 틀리게 바꾸면, 그 자리에 **⚠ 아이디**가 보여요. 원래 아이디로 되돌리면 됩니다.
- GitHub에서는 파일의 **History**에서 예전 내용을 볼 수 있고, 되돌릴 수도 있어요.
- 개발하는 쪽에서는 `node tools/validate-texts.mjs`로 빠진 글 · 겹친 아이디 · 빠진 `{자리}`를 한 번에 확인할 수 있어요.
