# 3·1 만세 전야 · 홀로 하는 밤

『3·1 만세 전야』 보드게임의 규칙을 그대로 쓰는, 혼자서 짧게 즐기는 모바일 1인 퍼즐 PWA(테스트판)입니다.
외부 라이브러리 없이 바닐라 JS(ES 모듈) + HTML + CSS만으로 만들었고, GitHub Pages 같은 정적 호스팅에 그대로 올릴 수 있습니다.

## 1. 실행 방법

정적 파일이므로 아무 정적 서버로 열면 됩니다. `fetch('data/levels.json')`를 쓰기 때문에 `file://`로 직접 열면 브라우저 보안 정책상 막힐 수 있어, 반드시 로컬 서버를 통해 여세요.

```bash
# 이 폴더(index.html이 있는 폴더)에서
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```

## 2. 배포 방법 (GitHub Pages)

1. 이 폴더 전체(= `index.html`이 있는 최상위)를 저장소에 커밋합니다.
2. 저장소 Settings → Pages에서 브랜치와 루트 폴더를 지정해 배포합니다.
3. 배포된 주소로 모바일 브라우저에서 접속 후 "홈 화면에 추가"하면 아이콘이 생기고, 이후 오프라인에서도 실행됩니다(서비스 워커가 첫 접속 때 앱 파일을 캐시해 둡니다).

## 3. 폴더 구조

```
index.html            화면 골격 + 모든 CSS(내장)
js/engine.js           판정 엔진 — 원본 v0.9.9 로직을 한 글자도 바꾸지 않고 옮김(주석 참고)
js/levelSetup.js        레벨 → 엔진 설정 변환, 막힌 판 검사, 자유 연습 시드
js/solo.js              1인 모드 진행 · 저장(localStorage)
js/multi.js             자유 연습: 3~5명(사람 · AI) 함께 하기 — SoloGame 확장, AI 한 걸음씩 진행
js/art.js               태극기 · 괘 · 등잔 SVG를 코드로 그리고, 주사위 그림을 표시하는 모듈
js/ui.js                화면 그리기 · 입력 연결(라우터)
js/story.js             스무하루의 밤 이야기 카드(1919년 2월 8일 ~ 3월 1일)

manifest.json / sw.js   PWA 매니페스트 / 오프라인 캐시
```

## 4. 레벨 데이터 형식과 추가 방법

`data/levels.json`은 레벨 객체의 배열입니다. 필드:

- `id`, `region`, `title` — 식별자 · 지역 · 이름
- `tutorial` — true면 안내 단계(별점 기준을 느슨하게 검사)
- `nights`, `poolSize` — 밤 수, 밤마다 꺼내는 주사위 수
- `seed` — mulberry32 정수 시드
- `eyeChance` — 감시의 눈(1) 확률. `null`이면 균등 1/6
- `startEyes` — 시작 시 판에 미리 놓인 감시의 눈 칸 번호 배열(0~8)
- `scriptedPools` — 튜토리얼 전용. `[[색,눈], ...]`를 밤별로 지정하면 그 밤은 주머니 대신 이 배열을 그대로 씀
- `goal`, `stars` — 목표 조건과 별 1 · 2 · 3 점수 기준
- `intro`, `tips` — 안내 문구

새 레벨을 추가하려면 객체를 배열에 추가한 뒤 `node tools/validate-levels.mjs 300`으로 검증하세요. 이 스크립트는 보통 AI(엔진 내장 AI)와 숙련 AI(2수 앞 탐색을 직접 구현) 양쪽으로 각 레벨을 300판씩 시뮬레이션해, 막힌 판 여부 · 별 1 달성률 · 점수 분포를 보고합니다.

## 5. 설계상 단순화한 부분 (알아두면 좋은 점)

- **튜토리얼의 `scriptedPools`는 주머니를 건드리지 않습니다.** 지정된 주사위가 주머니에서 나가거나 돌아가지 않고 그대로 화면에 등장합니다. 튜토리얼은 짧은 1회성 안내 플레이라 주머니 수량의 장기적 일관성이 중요하지 않다고 보고 택한 단순화입니다. 캠페인 6단계 이후와 자유 연습은 모두 정상적으로 주머니에서 뽑습니다.
- **감시를 밀어낸 보너스(룰북 v1.0 [잠정])**: 한뜻 무리로 판의 감시의 눈을 밀어내면 1점. 모든 모드에 기본으로 적용됩니다. 감시 철수로 빠진 감시의 눈에는 점수가 없습니다. 캠페인 별 기준 점수는 이 규칙 이전에 맞춘 것이라 별 받기가 조금 쉬워졌을 수 있습니다.
- **기본 규칙만 지원합니다.** 룰북의 심화 규칙(「괘 맞추기」)은 1인 모드 범위 밖이라 넣지 않았습니다. 모든 무리의 보상은 원하는 조각 자유 선택입니다.
- **게임 익히기(옛 팔도 캠페인)**: 타이틀에서 바로 단계 목록으로 들어갑니다(지역 고르기 화면 없음).
- **점수·연출 그래픽은 코드 생성 SVG**입니다(`js/art.js`). 태극·괘·등잔은 외부 이미지 파일 없이 벡터로 그렸고, 주사위만 `img/dice/`의 그림을 씁니다. 그림 속 숫자가 작은 화면에서 잘 안 보여, 2~6에는 큰 숫자 표시를 코드로 덧그립니다.

## 6. 완성도 체크리스트 (제작요청서 10장 기준)

- [x] 360px 너비 화면에서 가로 스크롤 없이 표시(모든 폭 가변 요소는 `min(vw, px)` 또는 grid 사용)
- [x] 세 가지 모드(게임 익히기 · 스무하루의 밤 · 자유 연습) 모두 플레이 가능
- [x] 자유 연습: 3~5인, 자리마다 플레이어/AI 선택, 플레이어 이름 저장(자리 구성 · 이름 추천 목록), 끝나면 전원 순위·점수
- [x] 자유 연습 점수판 「3월 1일로 가는 길」(코드로 그림): 점수가 오르면 말이 한 칸씩 이동, 같은 칸은 나중에 온 말이 위(룰북 v0.9.9), 이번 밤 고르는 순서 표시, 끝나면 행렬 맨 앞 지방이 태극기를 듦
- [x] 스무하루의 밤: 1919년 2월 8일 ~ 28일 21밤, 밤마다 이야기 카드(`js/story.js`), 끝까지 버티면 3월 1일 이야기. 막힌 판(가로·세로 모든 줄에 감시의 눈) 또는 종료 버튼으로 중도 종료, 최고 기록 저장
- [x] 게임 익히기 12단계(안내 5 + 본편 7), 별 기반 순차 해금, 진행도 저장
- [x] "홈 화면에 추가" 후 오프라인 실행(서비스 워커 캐시)
- [x] 레벨 난이도 검증 스크립트로 전 레벨 통과 확인 (`validate_report.txt` 참고용 로그는 개발 중 산출물이며 최종 배포물에는 포함하지 않음)

## 7. 알려진 한계 / 다음에 할 일

- 자동화된 UI(DOM) 테스트는 없습니다. 엔진 · 1인 모드 진행 로직은 Node 환경에서 여러 레벨을 끝까지 시뮬레이션해 예외 없이 완주되는 것과, 무리 순서 선택 · 남기기 · 감시의 눈 제거 · 조각 선택 단계에서 화면(`js/ui.js`)이 기대하는 값의 모양(줄 번호 배열, 조각 키 배열 등)이 실제로 그렇게 나오는지를 직접 재생해 확인했지만, 실제 브라우저에서의 손끝 조작(터치 좌표, 애니메이션 타이밍)은 검증하지 못했습니다.
- 접근성(스크린리더 라벨 등)은 별도로 다듬지 않았습니다.
