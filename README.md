# 3·1 만세 전야 · 홀로 하는 밤

『3·1 만세 전야』 보드게임의 규칙을 그대로 쓰는 모바일 퍼즐 게임(PWA, 테스트판)입니다. 혼자서 짧게 즐기거나, AI · 친구와 한 기기로 함께 할 수 있습니다.
외부 라이브러리 없이 HTML · CSS · JavaScript만으로 만들었고, 휴대폰 브라우저에서 "홈 화면에 추가"하면 앱처럼 설치되어 오프라인에서도 실행됩니다.

```bash
# index.html이 있는 폴더에서 정적 서버를 띄운 뒤 http://localhost:8000 접속
python3 -m http.server 8000
```

## 게임 소개

> 1919년 3월 1일을 앞둔 밤, 사람들은 각자의 자리에서 태극기를 준비했습니다. 누가 시킨 일이 아니었습니다.

여러분은 한 지방에서 삼일운동을 준비하는 **조직가**입니다. 밤마다 찾아오는 사람들에게 알맞은 자리를 찾아 주고, 뜻이 맞는 사람들을 모아 **태극기 조각**을 찍습니다. 여덟 밤 동안 조각을 모아 태극기를 완성하며 3월 1일 아침을 향해 나아갑니다.

### 사람 주사위

주사위 하나하나가 그날 찾아온 사람입니다. **색**은 어떤 사람들인지, **눈**은 그 사람이 찍어 낼 수 있는 조각을 뜻합니다.

| 색 | 사람들 |
|---|---|
| 흰색 | 마을과 장터 사람들 |
| 검정 | 도시의 일하는 사람들 |
| 빨강 | 학생과 젊은이들 |
| 파랑 | 신앙의 사람들 |

눈 2 - 6은 태극 · 건 · 리 · 감 · 곤 조각입니다. 눈 **1은 밀정**으로, 사람들 사이에 섞여 든 감시자라 어떤 모둠에도 들어갈 수 없습니다.

### 한 밤의 흐름

1. 주머니에서 주사위를 꺼내 굴려 **광장**에 둡니다.
2. 광장에서 주사위를 하나 골라 3×3 지방 판에 놓기를 **두 번** 합니다. 처음엔 어느 칸에든, 그다음부터는 이미 놓인 주사위의 상하좌우 빈칸에만 놓을 수 있습니다.
3. 데려온 사람은 밀정이라도 반드시 놓아야 합니다. 남은 주사위는 주머니로 돌아갑니다.

### 모둠

가로나 세로 한 줄이 주사위 셋으로 가득 차면 모둠이 되는지 봅니다.

| 모둠 | 조건 | 받는 것 |
|---|---|---|
| **한뜻** | 눈이 모두 같고 색이 모두 다름 | 판의 밀정 하나 쫓아내기(+1점) + 원하는 조각 2개 |
| **연락망** | 색이 모두 같고 눈이 이어짐(2·3·4 / 3·4·5 / 4·5·6) | 원하는 조각 2개 |
| **한동네** | 색이 모두 같고 눈이 모두 다름(이어지지 않음) | 원하는 조각 1개 |

- 모둠이 되면 셋 중 **한 사람을 남기고** 둘은 주머니로 돌아갑니다. 남긴 사람이 다음 모둠의 씨앗이 됩니다.
- 주사위 하나로 가로와 세로가 동시에 모둠이 되면 **교차 완성**, 두 모둠의 보상을 모두 받습니다.
- 줄이 가득 찼는데 모둠이 아니면 **흩어집니다**. 밀정만 남고 나머지는 주머니로 돌아갑니다.
- 한 줄이 밀정 셋으로만 차면 **감시 철수**로 셋 모두 사라집니다(점수 없음).

### 점수

**점수 = 찍은 조각 수 + 완성한 태극기 장 수 + 쫓아낸 밀정 수**

태극 · 건 · 리 · 감 · 곤 다섯 자리를 모두 찍으면 태극기 한 장이 완성되어 1점을 더 받습니다.

자세한 규칙은 게임 안의 「규칙 보기」와 `docs/3·1 만세 전야 룰북_v1_1.md`에 있습니다. 앱은 기본 규칙만 지원합니다(심화 규칙 「괘 맞추기」는 넣지 않았습니다).

## 놀이 방법

### 첫 걸음

처음 하는 사람을 위한 과정입니다. 장면 하나에 개념 하나씩, 미리 짜 둔 판에서 코치 말풍선을 따라 직접 놓아 보며 규칙을 익힙니다. 8 - 12분쯤 걸립니다.

- 사람 주사위 → 놓기 → 한동네 · 연락망 · 한뜻 → 한 사람 남기기 → 흩어짐 → 밀정 → 감시 철수 → 교차 완성 → 태극기 완성 → 안내 없이 세 밤
- 눌러야 할 곳을 반짝여 알려 주고, 틀리게 고르면 막은 뒤 힌트를 줍니다. 같은 곳에서 두 번 틀리면 정답을 보여 줍니다.
- 이어 하기 · 처음부터 · 장면 골라 보기를 할 수 있고, 이미 아는 사람은 과정을 건너뛸 수 있습니다.

### 스무하루의 밤

1919년 2월 8일 2·8 독립선언부터 2월 28일까지 스물한 밤을 혼자 버팁니다. 밤마다 그 무렵 3·1 운동을 준비하던 이야기 카드가 펼쳐지고, 끝까지 버티면 3월 1일 새벽 이야기를 만납니다. 가로 세 줄과 세로 세 줄 모두에 밀정이 자리 잡으면 판이 막혀 끝납니다. 최고 기록이 저장됩니다.

### 단속의 밤

조각 대신 **숨겨 둔 태극기**를 지키는 놀이입니다. 태극기 3장을 숨겨 두고 시작해 여덟 밤을 보냅니다.

- 한 밤은 손 네 번이고, 손마다 주사위 4개 중 2개를 놓습니다.
- 한뜻 · 연락망은 태극기 2장, 한동네는 1장을 더 숨깁니다. 손에서 밀정을 놓으면 1장을 빼앗깁니다.
- 밤이 끝나면 그날의 단속 카드에 표시된 칸을 살펴, 비어 있으면 밀정이 들어와 1장을 빼앗아 갑니다. 3월 1일이 다가올수록 단속이 거세집니다.
- 숨겨 둔 태극기가 0장이 되면 끝나고, 끝까지 지키면 손에 든 장 수로 별을 받습니다(★1장 ★★6장 ★★★10장).

### 자유 연습

3 - 5명이 AI나 친구와 함께 여덟 밤을 겨룹니다. 친구와는 한 기기를 돌려 가며 둡니다.

- 자리마다 플레이어 / AI를 고르고, 이름을 저장해 둘 수 있습니다.
- 점수판 「3월 1일로 가는 길」에서 가장 뒤에 있는 사람부터 고르고, 여덟 밤 뒤 가장 앞선 사람이 이깁니다.

### 그 밖의 기능

- **규칙 보기**: 게임 소개, 모둠, 점수, 놀이 방법별 규칙, 주사위 속 사람들
- **설정**: 도움 표시(놓으면 흩어지는 칸 표시) · 배경음 · 효과음
- **소리**: 3/4박자의 배경음과 놓기 · 모둠 · 흩어짐마다 울리는 북소리
- **오프라인 실행**: 한 번 접속하면 앱 파일을 저장해 두어 인터넷 없이도 실행됩니다.
