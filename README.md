# 3·1 만세 전야 · 홀로 하는 밤

『3·1 만세 전야』 보드게임의 규칙을 그대로 쓰는, 혼자서 짧게 즐기는 모바일 1인 퍼즐 PWA(테스트판)입니다.
외부 라이브러리 없이 바닐라 JS(ES 모듈) + HTML + CSS만으로 만들었고, GitHub Pages 같은 정적 호스팅에 그대로 올릴 수 있습니다.

## 1. 실행 방법

정적 파일이므로 아무 정적 서버로 열면 됩니다. `fetch('data/crackdown.json')`을 쓰고 ES 모듈로 불러오기 때문에 `file://`로 직접 열면 브라우저 보안 정책상 막힐 수 있어, 반드시 로컬 서버를 통해 여세요.

```bash
# 이 폴더(index.html이 있는 폴더)에서
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```

## 2. 배포 방법 (GitHub Pages)

1. 이 폴더 전체(= `index.html`이 있는 최상위)를 저장소에 커밋합니다.
2. 저장소 Settings → Pages에서 브랜치와 루트 폴더를 지정해 배포합니다.
3. 배포된 주소로 모바일 브라우저에서 접속 후 "홈 화면에 추가"하면 아이콘이 생기고, 이후 오프라인에서도 실행됩니다(서비스 워커가 첫 접속 때 앱 파일을 캐시해 둡니다).

## 4. 첫 걸음 장면 형식과 고치는 방법

첫 걸음은 장면 13개(장면 0 - 12)와 끝 장면으로 이어지는 하나의 과정입니다. 기획은 `docs/첫걸음_개편_시나리오.md`, 장면 데이터는 `js/tutorial.js`의 `TUTORIAL_SCENES`에 있습니다.

- `kind` — `story`(이야기 카드) · `dice`(주사위 눌러 보기) · `play`(판에서 직접 놓기)
- `nights`, `seed`, `poolSize` — 밤 수, 시드, 밤마다 꺼내는 주사위 수(play)
- `startBoard` — 시작 판. `{ 칸: [색, 눈] }`, 칸 번호 0 - 8
- `startRecord` — 미리 찍어 둔 조각. `{ taegeuk: 1, ... }`
- `scriptedPools` — 밤별 광장. `[[색,눈], ...]`를 밤마다 지정하면 주머니 대신 그대로 씀
- `steps` — 코치 말풍선 단계. 형식은 `js/tutorial.js` 맨 위 주석 참고(다음 · 놓기 · 남기기 · 조각 · 순서, 퀴즈, 틀렸을 때 힌트)
- `summary` — 장면 끝 정리 카드(주사위 · 한 줄 요약 · 더 알아두기 판)
- `goal` — 첫 밤길(장면 12)의 목표. 모둠 수 또는 점수

장면을 고친 뒤에는 `node tools/validate-tutorial.mjs`로 검증하세요. 모든 play 장면을 단계대로 둬 보고, 단계가 엔진 진행과 맞물리는지 · 끝난 점수와 모둠 수가 시나리오와 같은지 · 퀴즈에서 틀린 선택이 막히는지 확인합니다.

진행도는 장면 단위로 저장합니다(`manse-eve:v1:tutorial` = `{ reached, done }`). 별점은 없고, 끝까지 마치거나 건너뛰면 "마침"으로 표시합니다.

## 5. 설계상 단순화한 부분 (알아두면 좋은 점)

- **첫 걸음의 `scriptedPools`는 주머니를 건드리지 않습니다.** 지정된 주사위가 주머니에서 나가거나 돌아가지 않고 그대로 화면에 등장합니다. 짧은 1회성 안내 플레이라 주머니 수량의 장기적 일관성이 중요하지 않다고 보고 택한 단순화입니다. 첫 밤길(장면 12)과 다른 모드는 모두 정상적으로 주머니에서 뽑습니다.
- **첫 걸음에서 판의 밀정이 하나뿐이면 한뜻이 바로 쫓아냅니다.** 엔진이 밀정이 하나일 때는 고르는 단계 없이 쫓아내므로, 장면 8 · 10은 누르는 대신 쫓겨나는 모습을 말풍선으로 설명합니다.
- **밀정을 쫓아냄(룰북 v1.1)**: 한뜻 모둠으로 판의 밀정(1)을 쫓아내면 1점. 모든 모드에 적용됩니다. 감시 철수로 빠진 밀정에는 점수가 없습니다.
- **단속의 밤은 엔진을 감싸서 만들었습니다.** 손 한 번 = 엔진의 라운드 한 번(광장 4개 · 두 번 놓기)이고, 밤 경계에서 `maxRounds`를 늘려 이어 갑니다. 조각 고르기는 자동으로 넘기고 모둠 수로 장 수를 셉니다. 낮 밀정의 줄 정리(흩어짐 → 감시 철수)는 엔진의 같은 절차를 `js/crackdown.js`의 `resolveLinesAt`에 옮겨 썼습니다. 엔진의 주머니에는 색만 있고 눈은 꺼낼 때 굴리므로, 낮 밀정은 "주머니에서 색 하나를 꺼내 눈 1로 놓기"이고 주머니가 완전히 비었을 때만 건너뜁니다. 숫자 값은 모두 `CRACKDOWN_CONFIG`에 있습니다.
- **기본 규칙만 지원합니다.** 룰북의 심화 규칙(「괘 맞추기」)은 1인 모드 범위 밖이라 넣지 않았습니다. 모든 모둠의 보상은 원하는 조각 자유 선택입니다.
- **첫 걸음은 하나로 이어지는 과정입니다(옛 12단계 캠페인을 대신함).** 장면 하나에 개념 하나씩, 미리 짜 둔 판에서 말풍선을 따라 직접 놓습니다. 틀린 선택은 엔진에 넘기지 않고 막은 뒤 힌트를 주고, 같은 단계에서 두 번 틀리면 정답을 반짝여 보여 줍니다.
- **점수·연출 그래픽은 코드 생성 SVG**입니다(`js/art.js`). 태극·괘·등잔은 외부 이미지 파일 없이 벡터로 그렸고, 주사위만 `img/dice/`의 그림을 씁니다. 그림 속 숫자가 작은 화면에서 잘 안 보여, 2~6에는 큰 숫자 표시를 코드로 덧그립니다.

## 6. 완성도 체크리스트 (제작요청서 10장 기준)

- [x] 360px 너비 화면에서 가로 스크롤 없이 표시(모든 폭 가변 요소는 `min(vw, px)` 또는 grid 사용)
- [x] 네 가지 모드(첫 걸음 · 스무하루의 밤 · 단속의 밤 · 자유 연습) 모두 플레이 가능
- [x] 자유 연습: 3~5인(룰북은 3~4명, 앱은 5명까지 허용 · 5명이면 광장 12개), 자리마다 플레이어/AI 선택, 플레이어 이름 저장(자리 구성 · 이름 추천 목록), 끝나면 전원 순위·점수
- [x] 자유 연습 점수판 「3월 1일로 가는 길」(코드로 그림): 점수가 오르면 말이 한 칸씩 이동, 같은 칸은 나중에 온 말이 위(룰북 v1.1), 이번 밤 고르는 순서 표시, 끝나면 행렬 맨 앞 지방이 태극기를 듦
- [x] 스무하루의 밤: 1919년 2월 8일 ~ 28일 21밤, 밤마다 이야기 카드(`js/story.js`), 끝까지 버티면 3월 1일 이야기. 막힌 판(가로·세로 모든 줄에 밀정) 또는 종료 버튼으로 중도 종료, 최고 기록 저장
- [x] 단속의 밤: 여덟 밤 · 밤마다 손 4번(4개 중 2개 놓기) · 낮 단속 7번 — 이야기는 초반 3 + 후반 4장을 사건 순서(order)대로, 밀정 칸은 따로 섞어 초반 1칸 · 후반 2칸 · 마지막 한 번만 3칸(시드 고정) · 모둠은 태극기 장 수로 자동 합산(조각 고르기 없음) · 밀정이 판에 들어오면 압수 · 0장이면 즉시 실패 · 별과 최고 기록 저장
- [x] 단속의 밤 시뮬레이션: `node tools/simulate-crackdown.mjs 1000` (옵션 `--start-flags= --stars=1,6,10 --self-spy=0|1 --early= --late= --final= --seed= --trace`)
- [x] 첫 걸음: 장면 13개 + 끝, 이어 하기 · 처음부터 · 장면 골라 보기 · 과정 건너뛰기, 장면 단위 진행도 저장, 별점 없이 "마침" 표시
- [x] "홈 화면에 추가" 후 오프라인 실행(서비스 워커 캐시)
- [x] 첫 걸음 장면 검증 스크립트로 전 장면 통과 확인(`node tools/validate-tutorial.mjs`)

## 7. 알려진 한계 / 다음에 할 일

- 자동화된 UI(DOM) 테스트는 없습니다. 엔진 · 1인 모드 진행 로직은 Node 환경에서 끝까지 시뮬레이션해 예외 없이 완주되는 것과, 모둠 순서 선택 · 남기기 · 밀정 쫓아내기 · 조각 선택 단계에서 화면(`js/ui.js`)이 기대하는 값의 모양(줄 번호 배열, 조각 키 배열 등)이 실제로 그렇게 나오는지를 직접 재생해 확인했지만, 실제 브라우저에서의 손끝 조작(터치 좌표, 애니메이션 타이밍)은 검증하지 못했습니다.
- 접근성(스크린리더 라벨 등)은 별도로 다듬지 않았습니다.
