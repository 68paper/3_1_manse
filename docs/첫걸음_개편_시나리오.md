# 「첫 걸음」 개편 시나리오 (초안)

> 코드로 옮기기 전에 장면 하나하나를 슬라이드처럼 정리한 기획 문서입니다.
> 규칙 기준은 `docs/3·1 만세 전야 룰북_v1_1.md`, 용어는 앱이 쓰는 이름(한뜻 · 연락망 · 한동네 · 흩어짐 · 감시 철수)을 따릅니다.

## 1. 개편 방향

| 지금 | 개편 후 |
|---|---|
| 12단계 목록(안내 5 + 본편 7), 단계마다 별을 모아 다음 단계를 엶 | **하나로 이어지는 과정** — 처음부터 끝까지 한 흐름으로 진행 |
| 안내 단계 하나에 개념 여러 개를 섞어 설명(예: 4단계 "밀정과 흩어짐") | **장면 하나에 개념 하나** — 직접 놓아 보며 익힘 |
| 시작 판에 밀정만 미리 놓을 수 있음(`startEyes`) | 장면마다 **판을 미리 짜 둠** — 개념을 보여 주기 딱 좋은 상황에서 시작 |
| 설명은 단계 시작 때 한 번(`intro`, `tips`) | 놓을 때마다 **코치 말풍선**이 다음 행동을 안내 |

## 2. 화면 공통 요소

```
┌────────────────────────────┐
│ ← 첫 걸음      ●●●○○○○○○○○○○  │  ← 진행 점(장면 13개)
├────────────────────────────┤
│  ╭──────────────────────╮  │
│  │ 코치 말풍선           │  │  ← 지금 할 일을 한두 문장으로
│  ╰──────────────────────╯  │
│                            │
│      [  ] [  ] [  ]        │
│      [  ] [  ] [  ]        │  ← 지방 판(3×3)
│      [  ] [  ] [  ]        │
│                            │
│  광장: (흰6) (검3) (빨4) (파2) │
│                            │
│  조각 · 점수        [다시 하기] │
└────────────────────────────┘
```

| 요소 | 동작 |
|---|---|
| 코치 말풍선 | 단계마다 바뀜. 눌러서 다음으로 넘기는 설명형과, 행동을 기다리는 안내형 두 가지 |
| 반짝임 강조 | 지금 눌러야 할 주사위 · 칸에 테두리가 반짝임 |
| 잠금 | 안내형 단계에서는 강조된 것만 누를 수 있고, 나머지는 흐리게 표시 |
| 틀렸을 때 | 잠긴 것을 누르면 살짝 흔들리고 말풍선에 힌트(벌칙 없음) |
| 다시 하기 | 지금 장면을 처음 판으로 되돌림 |
| 정리 카드 | 장면 끝에 배운 규칙을 한 장으로 보여 줌(주사위 그림 + 한 줄 요약) |
| 이어 하기 | 장면 단위로 저장. 다시 들어오면 마지막으로 마친 장면 다음부터 |

### 판 칸 번호(아래 시나리오에서 사용)

```
0 1 2
3 4 5
6 7 8
```

표기: `흰2` = 흰색 눈 2, `검1` = 밀정(색과 상관없이 눈 1은 모두 밀정)

## 3. 장면별 시나리오

---

### 장면 0. 그날 밤

> 배울 것: 나는 누구이고, 무엇을 하는가

**화면**: 등잔 하나가 켜진 어두운 방. 이야기 카드 두 장을 넘깁니다.

| 카드 | 문구(초안) |
|---|---|
| 1 | 1919년 3월 1일을 앞둔 밤, 사람들은 각자의 자리에서 태극기를 준비했어요. 누가 시킨 일이 아니었어요. |
| 2 | 당신은 한 지방의 **조직가**예요. 밤마다 찾아오는 사람들에게 알맞은 자리를 찾아 주고, 뜻이 맞는 사람들을 모아 **태극기 조각**을 찍어요. |

**넘어가기**: [시작하기] 버튼

---

### 장면 1. 찾아온 사람들

> 배울 것: 주사위 하나 = 사람 한 명. 색은 어떤 사람들인지, 눈은 순서. 1은 밀정.

**화면**: 판 없이 주사위 다섯 개만 가운데에 놓여 있습니다.

```
(흰3) (검4) (빨2) (파5) (검1)
```

| 단계 | 코치 말 | 플레이어 | 화면 반응 |
|---|---|---|---|
| 1 | 주사위 하나하나가 그날 찾아온 사람이에요. 눌러 보세요. | 아무 주사위나 누름 | 주사위가 커지며 사람 이름과 무리 표시. 예) 흰3 → "마을 어른 · 마을과 장터 사람들" |
| 2 | **색**은 어떤 사람들이 모였는지 알려 줘요. 나머지도 눌러 보세요. | 네 색을 모두 눌러 봄 | 누른 주사위에 체크 |
| 3 | **눈**은 2부터 6까지, 순서일 뿐이에요. 누가 더 높은 사람이 아니에요. | 말풍선 누름 | 눈 숫자가 잠깐 강조 |
| 4 | 그런데 한 명이 이상해요. 눌러 보세요. | 검1 누름 | 중절모 그림 확대, "밀정 — 사람들 사이에 섞여 든 감시자" |
| 5 | 1은 색과 상관없이 모두 **밀정**이에요. 밀정은 어떤 모둠에도 들어갈 수 없어요. | 말풍선 누름 | 정리 카드로 |

**정리 카드**: 흰 마을과 장터 · 검 도시의 일하는 사람들 · 빨 학생과 젊은이들 · 파 신앙의 사람들 / 1 = 밀정

---

### 장면 2. 자리 찾아 주기

> 배울 것: 광장에서 하나 고르고 놓기를 두 번. 첫 주사위는 어디든, 그다음은 상하좌우 빈칸. 남은 주사위는 주머니로.

**시작 화면**

```
판(비어 있음)         광장
[  ][  ][  ]        (빨2) (검3) (흰4) (파5)
[  ][  ][  ]
[  ][  ][  ]
```

| 단계 | 코치 말 | 플레이어 | 화면 반응 |
|---|---|---|---|
| 1 | 밤이 되면 사람들이 **광장**에 모여요. 한 사람을 골라 보세요. | 아무 주사위나 고름 | 고른 주사위가 떠오름 |
| 2 | 판이 비어 있으면 **어느 칸에든** 놓을 수 있어요. | 아무 칸이나 누름 | 놓임 |
| 3 | 한 사람 더 맞이해요. 이번엔 놓을 수 있는 칸이 정해져 있어요. | 주사위 고름 | 놓인 주사위의 **상하좌우 빈칸**만 반짝임 |
| 4 | (대각선을 누르면) 대각선은 안 돼요. 이미 있는 사람 바로 옆에 세워 주세요. | 반짝이는 칸 누름 | 놓임 |
| 5 | 한 밤에 맞이하는 사람은 둘이에요. 남은 사람들은 **주머니**로 돌아가요. | 말풍선 누름 | 광장의 두 주사위가 주머니로 날아감, 등잔 한 칸 |
| 6 | 한 번 데려온 사람은 **반드시** 놓아야 해요. 찾아온 사람을 돌려보내지 않아요. | 말풍선 누름 | 정리 카드로 |

**정리 카드**: 한 밤 = 고르고 놓기 × 2 · 상하좌우 빈칸에만(대각선 ✕) · 데려온 사람은 꼭 놓기

### 장면 3. 한동네 — 같은 마을 사람들

> 배울 것: 한 줄이 셋으로 가득 차면 모둠인지 본다. 같은 색 · 다른 눈 = **한동네**, 조각 1개.

**시작 화면**

```
판                    광장
[흰2][흰5][  ]       (흰6) (검3) (빨4) (파2)
[  ][  ][  ]
[  ][  ][  ]
```

| 단계 | 코치 말 | 플레이어 | 화면 반응 |
|---|---|---|---|
| 1 | 윗줄에 마을 사람 둘이 서 있어요. 같은 **흰색**이죠. | 말풍선 누름 | 윗줄 강조 |
| 2 | 같은 마을 사람을 한 명 더 데려와 볼까요? | 흰6 고름(잠금) | 흰6만 누를 수 있음 |
| 3 | 윗줄 빈칸에 세워 주세요. | 칸 2에 놓음(잠금) | 윗줄이 가득 참 → "한동네!" 연출 |
| 4 | 색이 모두 같고 눈이 모두 다르면 **한동네**예요. | 말풍선 누름 | 세 주사위 묶음 표시 |
| 5 | 모둠은 한 사람만 남고 나머지는 돌아가요. (누구를 남길지는 뒤에서 배워요) | 말풍선 누름 | 방금 놓은 흰6이 자동으로 남고 흰2 · 흰5는 주머니로 |
| 6 | 한동네는 **태극기 조각 1개**를 찍어요. 태극 · 건 · 리 · 감 · 곤 중 무엇이든 골라요. | 조각 하나 고름 | 기록지에 도장, 점수 +1 |
| 7 | 한 사람 더 맞이하고 이 밤을 마쳐요. | 남은 셋 중 하나를 골라 놓음(자유) | 밤 마침 |

**잘못 골랐을 때**: 흰6이 아닌 주사위를 누르면 → "윗줄은 흰색 사람들이에요. 같은 색을 찾아보세요."

**정리 카드**: 🎲🎲🎲 흰2 · 흰5 · 흰6 — 한동네: 같은 색 · 다른 눈 → 조각 1개

### 장면 4. 연락망 — 한 사람에게서 다음 사람으로

> 배울 것: 같은 색 · 이어진 눈(2·3·4 / 3·4·5 / 4·5·6) = **연락망**, 조각 2개. 놓인 순서는 상관없음.

**시작 화면**

```
판                    광장
[  ][  ][  ]         (파4) (파6) (흰4) (검2)
[파5][  ][파3]
[  ][  ][  ]
```

| 단계 | 코치 말 | 플레이어 | 화면 반응 |
|---|---|---|---|
| 1 | 가운데 줄에 파랑 5와 파랑 3이 있어요. 둘 사이에 누가 서면 뜻이 이어질까요? | 광장에서 고름(퀴즈) | 파4를 고르면 정답 연출 |
| 2 | 맞아요. 가운데에 세워 주세요. | 칸 4에 놓음(잠금) | 5 · 4 · 3 → "연락망!" |
| 3 | 색이 같고 눈이 **이어지면** 연락망이에요. 5 · 4 · 3처럼 순서가 뒤섞여도 괜찮아요. | 말풍선 누름 | 주사위가 3 · 4 · 5 순으로 잠깐 정렬되어 보였다 돌아옴 |
| 4 | 연락망은 조각 **2개**를 찍어요. | 조각 2개 고름 | 점수 +2 |
| 5 | 한 사람 더 맞이하고 이 밤을 마쳐요. | 자유롭게 하나 놓음 | 밤 마침 |

**퀴즈에서 틀렸을 때**

| 고른 주사위 | 힌트 |
|---|---|
| 파6 | 같은 파랑이지만 5 · 6 · 3은 이어지지 않아요. 3과 5 사이의 눈은? |
| 흰4 | 눈은 맞았어요! 그런데 연락망은 색도 같아야 해요. |
| 검2 | 색도 눈도 이어지지 않아요. 3과 5 사이의 파랑을 찾아보세요. |

**정리 카드**: 🎲🎲🎲 파3 · 파4 · 파5 — 연락망: 같은 색 · 이어진 눈 → 조각 2개 / 같은 색이고 이어지면 연락망만 받음(한동네와 겹쳐 받지 않음)

### 장면 5. 한뜻 — 처지가 다른 사람들이 같은 뜻으로

> 배울 것: 같은 눈 · 모두 다른 색 = **한뜻**, 조각 2개(밀정 쫓아내기는 장면 8에서).

**시작 화면**

```
판                    광장
[  ][빨4][  ]        (흰4) (빨4) (파6) (검2)
[  ][검4][  ]
[  ][  ][  ]
```

| 단계 | 코치 말 | 플레이어 | 화면 반응 |
|---|---|---|---|
| 1 | 학생(빨강)과 도시의 일꾼(검정)이 같은 눈 4로 서 있어요. 처지는 달라도 뜻은 같아요. | 말풍선 누름 | 가운데 세로줄 강조 |
| 2 | 이 줄을 **한뜻**으로 만들 사람을 골라 보세요. | 광장에서 고름(퀴즈) | 흰4를 고르면 정답 |
| 3 | 아래 칸에 세워 주세요. | 칸 7에 놓음(잠금) | 빨4 · 검4 · 흰4 → "한뜻!" |
| 4 | 눈이 모두 같고 색이 **모두 달라야** 한뜻이에요. | 말풍선 누름 | 세 색이 차례로 빛남 |
| 5 | 한뜻은 조각 **2개**를 찍어요. 그리고 숨은 힘이 하나 더 있는데, 곧 알게 될 거예요. | 조각 2개 고름 | 점수 +2 |
| 6 | 한 사람 더 맞이하고 이 밤을 마쳐요. | 자유롭게 하나 놓음 | 밤 마침 |

**퀴즈에서 틀렸을 때**

| 고른 주사위 | 힌트 |
|---|---|
| 빨4 | 눈은 같지만 빨강이 이미 있어요. 한뜻은 색이 모두 달라야 해요. |
| 파6 · 검2 | 한뜻은 눈이 같아야 해요. 이 줄의 눈은 몇이죠? |

**정리 카드**: 🎲🎲🎲 빨4 · 검4 · 흰4 — 한뜻: 같은 눈 · 다른 색 → 조각 2개 + 밀정 쫓아내기

### 장면 6. 한 사람 남기기

> 배울 것: 모둠이 되면 셋 중 **한 사람을 직접 골라** 남긴다. 남긴 사람은 다음 모둠의 씨앗.

**시작 화면**

```
판                    광장
[빨3][  ][빨5]       (빨4) (흰4) (파2) (검6)
[  ][검4][  ]
[  ][  ][  ]
```

| 단계 | 코치 말 | 플레이어 | 화면 반응 |
|---|---|---|---|
| 1 | 윗줄에 빨강 3과 5. 무엇이 필요한지 이제 알죠? | 빨4 고름(잠금) | |
| 2 | 가운데에 세워 주세요. | 칸 1에 놓음(잠금) | 빨3 · 빨4 · 빨5 → "연락망!" |
| 3 | 이번에는 **누구를 남길지 직접** 골라요. 남은 사람은 다음 모둠의 씨앗이 돼요. | 빨3 · 빨4 · 빨5 중 하나 누름 | 고른 주사위가 걸친 세로줄이 옅게 표시됨(미리 보기) |
| 4 | (빨4를 남겼다면) 좋아요! 빨4 아래에 검4가 있죠? | 조각 2개 고름 | 빨3 · 빨5 주머니로, 점수 +2 |

**남길 사람을 다르게 골랐을 때(빨3 또는 빨5)**

> 빨3(빨5)을 남기면 가운데 세로줄이 비어요. 흰4를 데려와도 한뜻을 만들 수 없어요.
> [다시 골라 보기] [이대로 해 보기]

- [이대로 해 보기]를 고르면 그대로 진행하고, 밤이 끝난 뒤 "다시 해 볼까요?" 한 번 더 권합니다.

**더 알아두기 카드(플레이 없음)**

```
[흰2][검5][(파4)]   ← 칸 2에 파4를 놓으면
[  ][  ][ 파5 ]      오른쪽 세로줄 파4 · 파5 · 파6은 연락망,
[  ][  ][ 파6 ]      윗줄 흰2 · 검5 · 파4는 꽉 찼지만 모둠이 아니에요.
```

- 파4를 남기면 윗줄이 그대로 꽉 차 있어서 흩어지고, 남긴 파4도 함께 돌아가요.
- 파5나 파6을 남기면 칸 2가 비어 윗줄은 흩어지지 않아요.

> 남길 사람을 고를 때는 그 사람이 걸친 **다른 줄**도 살펴보세요.
> (흩어짐은 바로 다음 장면에서 배웁니다. 이 카드는 장면 7 뒤로 옮겨도 됩니다.)

**정리 카드**: 모둠 → 한 사람 남기고 둘은 주머니로 · 남긴 사람이 다음 모둠의 씨앗

### 장면 11. 태극기 완성

> 배울 것: 조각 1개 = 1점. 태극 · 건 · 리 · 감 · 곤 다섯 자리를 채우면 태극기 한 장 완성(+1). 점수 = 조각 + 태극기 + 쫓아낸 밀정.

**시작 화면** — 기록지가 미리 채워져 있음

```
기록지 1번 태극기: 태극 ✔  건 ✔  리 ✔  감 ✔  곤 □      점수 4

판                    광장
[  ][  ][  ]         (검6) (검3) (흰5) (빨2)
[  ][  ][  ]
[검2][검4][  ]
```

| 단계 | 코치 말 | 플레이어 | 화면 반응 |
|---|---|---|---|
| 1 | 지금까지 모은 조각이에요. 1번 태극기에 한 자리만 비어 있어요. 어디죠? | 기록지의 곤 자리 누름 | 곤 자리 반짝임 |
| 2 | 아랫줄을 모둠으로 만들어 조각을 받아요. | 검6 고름 → 칸 8 | 검2 · 검4 · 검6 → "한동네!" |
| 3 | 한동네는 조각 1개. 어떤 조각을 고를까요? | 곤 고름(권장, 잠금 아님) | 도장 쾅, 태극기 한 장이 색으로 채워지는 연출, 점수 +1 +1 |
| 4 | 다섯 자리가 모두 찍히면 **태극기 한 장 완성**, 1점을 더 받아요. | 말풍선 누름 | |
| 5 | 점수는 **조각 수 + 완성한 태극기 + 쫓아낸 밀정**이에요. | 말풍선 누름 | 5 + 1 + 0 = 6 계산식 표시 |
| 6 | 한 사람 더 맞이하고 이 밤을 마쳐요. | 자유롭게 하나 놓음 | 밤 마침 |

**곤이 아닌 조각을 골랐을 때**: 그대로 받고 "2번 태극기에 찍혔어요. 1번 태극기를 먼저 채우려면 비어 있는 자리를 고르면 돼요." 안내 후 진행합니다.

**정리 카드**: 조각 1개 = 1점 · 태극기 한 장 = +1점 · 밀정 쫓아냄 = +1점
